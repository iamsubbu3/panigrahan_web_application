Dev environment setup:

Windows:

1. Install node.js from https://nodejs.org (LTS)

2. MySQL Server from https://dev.mysql.com/downloads/mysql/8.0.html

3. Install and configure Git https://git-scom.com

4. Install VSCode

5. React + Vite:

From root folder install - npm create vite@latest client

6. Tailwind CSS:

npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p

Ubuntu:

1. sudo apt install mysql-server -y

2. Install Git:

sudo apt install git -y

3. Install VSCode

sudo snap install code --classic

4. Backend setup:
mkdir server
cd server
npm init -y
npm install express sequelize mysql2 jsonwebtoken bcryptjs cors dotenv
npm install -D nodemon

5. Front End
npm create vite@latest client
cd client
npm install
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
